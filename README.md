# deletex

Консольный инструмент для поиска и осторожного удаления программ в Fedora KDE.

- Ищет RPM-приложения с ярлыком `.desktop`, Flatpak и установки Qt Installer Framework в `/opt`.
- Показывает источник установки и детали до удаления.
- Для RPM проверяет транзакцию командой DNF с `--assumeno`, затем требует точный ID и подтверждение самого DNF.
- Flatpak удаляет через `flatpak uninstall` без `--delete-data` и без связанных расширений; у Flatpak здесь нет предварительного расчёта транзакции.
- Установки с собственным `maintenancetool` (например, AmneziaVPN) **только обнаруживает**: автоматическое удаление заблокировано.
- Не ищет все ручные установки и AppImage. Поиск по имени не гарантирует обнаружения всех связанных файлов.

## Установка

Требуются Python 3.10+, Fedora с RPM/DNF; Flatpak и `fzf` — по желанию. Без `fzf` доступно текстовое меню. Скачайте файл [`deletex`](deletex) и установите его в каталог из `PATH`:

```bash
install -Dm755 deletex ~/.local/bin/deletex
```

## Использование

```bash
deletex                               # интерактивное меню
deletex search firefox                # поиск приложений
deletex search --all systemd-libs     # также RPM без ярлыка (включая системные)
deletex inspect rpm:firefox.x86_64    # предпросмотр, без удаления
deletex remove rpm:firefox.x86_64     # только с подтверждением
deletex search amnezia                # обнаружение установки в /opt
```

**Внимание:** `--all` показывает и системные пакеты. Перед подтверждением удаления RPM всегда читайте полный список пакетов в транзакции DNF. Удаление сторонних установщиков может затронуть службы и пользовательские данные; deletex их не запускает.

Оформление меню ориентировано на `pm` и `updatex`. Портрет: [blyxyas/uwu-neofetch-art](https://github.com/blyxyas/uwu-neofetch-art), CC0.
